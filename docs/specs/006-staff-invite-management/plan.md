# Implementation Plan: Staff Management — Provider Invite Flow

**Branch**: `006-staff-invite-management` | **Date**: 2026-06-08 | **Spec**: [spec.md](./spec.md)

## Summary

Provider mời nhân viên bằng email → nhân viên nhận link kích hoạt → đặt mật khẩu → tài khoản active. Provider có thể list, deactivate, reactivate, resend invite. Nhân viên khi đăng nhập thấy dữ liệu vận hành thực (today's bookings) thay vì mock. Tất cả đều được xây dựng trên infrastructure hiện có: `staff_cafe_assignments` table, `email.service.ts` (Brevo), JWT auth flow.

## Technical Context

**Language/Version**: TypeScript 5+ (strict), Node.js 20+  
**Primary Dependencies**: Express.js, TypeORM, bcrypt, jsonwebtoken, zod, Brevo HTTP API  
**Storage**: PostgreSQL — `users`, `staff_cafe_assignments` (existing), `staff_invite_tokens` (new)  
**Testing**: Jest (unit), supertest (integration)  
**Target Platform**: Linux server (Docker), React SPA (Vite)  
**Project Type**: Web application — REST API backend + React frontend  
**Performance Goals**: List endpoint < 200ms p95; invite creation < 1s (including Brevo call)  
**Constraints**: Email send failure must NOT block account creation (FR-003 clarification). JWT TTL 1h (existing).  
**Scale/Scope**: Single provider (~5–50 staff). No pagination required in v1.
